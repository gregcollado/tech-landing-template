# TechSoluciones

Sitio web sencillo para una empresa de soporte técnico y desarrollo de software.  
Incluye las secciones de inicio, nosotros, servicios y contacto.

## Tecnologías

- HTML5
- CSS3

## Cómo verlo

Abre el archivo `index.html` en un navegador web.

## Estructura principal

- `index.html`: página de inicio.
- `nosotros.html`: información de la empresa.
- `servicios.html`: servicios ofrecidos.
- `contacto.html`: información de contacto.
- `estilos.css`: estilos generales del sitio.
- `img/`: imágenes utilizadas en la página.

## Nota

El sitio aún no está configurado para ser responsive. La adaptación para celulares,
tabletas y diferentes tamaños de pantalla queda como trabajo futuro.
